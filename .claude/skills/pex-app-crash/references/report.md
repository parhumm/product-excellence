# Crash report fields

- Outcome and severity
- Package, version name/code and APK SHA prefix
- Crash/ANR kind, process, exception or reason
- First relevant app stack frame and a short sanitized excerpt
- Timeline and evidence IDs
- API, ABI, renderer, display, locale and applied network condition
- Reproduction status and coverage gaps
- Smallest next diagnostic or fix

Never copy unrelated log lines. A first sighting is not reproduced.
