# Product

## Register
product

## Users
QA and product teams evaluating web applications at a daytime desk. They need to define missions, watch execution, and assess reproducible evidence without writing browser tests.

## Product Purpose
Run user journeys, five-pillar audits and competitor benchmarks with subscription-authenticated AI and deterministic browser telemetry. Success is a real run with accountable results and useful evidence.

## Brand Personality
Calm, precise, practical. User confirmed on 2026-09-05.

## Anti-references
Marketing decoration, invented performance scores, generic metric cards, and simulated run results presented as real.

## Design Principles
Make the next action clear. Put evidence beside claims. Distinguish unavailable measurements from zero. Keep operations reversible. Prefer compact, familiar workflows.

## Accessibility & Inclusion
Keyboard operation, readable contrast, reduced motion, responsive layouts, and Persian/RTL evidence. Target WCAG AA.

## Confirmed task brief
Light console for daytime work. Linear-style navigation and Playwright-style evidence timelines. Mission → live run → findings. Production intent for the complete web console. Primary action: create and start a mission. Sections: overview, missions, runs, findings, benchmark, comparison, network, settings. States: empty, loading, running, blocked, failed, completed, interrupted. No mock success or unmeasured metrics. Forms validate inline; evidence opens in a detail pane. Confirmed by the user in this task.
